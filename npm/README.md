# hookspot

Command-line client for [Hookspot](https://hookspot.dev): prints incoming
webhook requests for a project and can forward them to a local HTTP server.

This package bundles prebuilt binaries for macOS, Linux, and Windows (amd64 and
arm64) and a launcher that runs the one matching your platform.

```sh
npm install -g hookspot
hookspot version --json
```

Usage, login, and the other install channels are documented in the
[hookspot-cli repository](https://github.com/hookspot/hookspot-cli#readme).
